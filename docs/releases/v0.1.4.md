# v0.1.4-research-preview

> Public cleanup release. Date: 2026-11-20.

## What changed

The public snapshot keeps only aggregate SciFact metrics and identifier-level
rows. Raw SciFact claims, abstracts, gold evidence text, per-claim predictions,
and the dataset archive are not redistributed.

Retained:

```text
eval/results/scifact_300_backends.json
eval/results/scifact_systems_300.json
```

Removed from the public tree:

```text
eval/gold/scifact_300.jsonl
eval/results/scifact_verification_*.json
other per-claim SciFact result files
```

## Why

SciFact is a third-party dataset under **CC BY-NC 2.0**. The repository code is
AGPL-3.0-or-later; the code license does not replace the dataset license.
Keeping raw claims/abstracts in a public code snapshot creates a needless
redistribution and attribution risk.

See `eval/SCIFACT.md` and `THIRD_PARTY_NOTICES.md`.
